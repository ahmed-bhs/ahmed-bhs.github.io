Hébergement dédié haute performance inclus 3 moisVoir le détail

Votre site tourne sur un serveur privé dédié (IaaS), pas sur un hébergement mutualisé ni sur une plateforme SaaS. Les ressources ne sont partagées avec aucun autre client : la charge d'un site voisin ne peut pas ralentir le vôtre, et une faille chez un tiers ne vous expose pas.

Le choix de l'IaaS plutôt que d'une plateforme clé en main a une conséquence directe pour vous : aucune dépendance à un éditeur. Le code, la base de données et la configuration serveur vous appartiennent et restent transférables chez un autre hébergeur. Pas d'abonnement propriétaire, pas de fonctionnalité bloquée derrière un palier tarifaire, pas de limite d'export.

Souveraineté des données

Vos données et celles de vos clients restent en France, chez un hébergeur français. Elles relèvent du droit européen et du RGPD, sans transfert hors Union européenne : contrairement à un hébergement chez un fournisseur américain, elles ne sont pas exposées aux lois d'accès extraterritoriales comme le CLOUD Act.

Concrètement, si un formulaire de contact, une prise de rendez-vous ou un fichier client transite par votre site, vous savez où ces informations sont stockées et sous quelle juridiction. C'est un point que vos propres clients peuvent vous demander, et une exigence courante dans les marchés publics et les appels d'offres.

Performance : cache HTTP et cache applicatif inclusVoir le détail

Une page déjà calculée est servie sans repasser par PHP ni par la base de données. Le visiteur reçoit la réponse en quelques millisecondes, et le serveur encaisse les pics de trafic sans ralentir.

Cache HTTP

Un cache de pages est placé devant l'application : la première visite calcule la page, les suivantes la reçoivent telle quelle. La durée de validité est réglée par type de contenu, et le cache est invalidé automatiquement dès qu'une page est modifiée depuis le back-office. Vos changements sont donc visibles immédiatement, sans purge manuelle.

Cache applicatif

Côté serveur, le framework travaille en mode production : routes, conteneur de services et gabarits sont compilés une fois puis réutilisés, au lieu d'être reconstruits à chaque visite. Le code PHP lui-même est conservé compilé en mémoire (OPcache, 192 Mo alloués, compilation JIT activée), ce qui évite de le réinterpréter à chaque requête. Sur les projets à forte charge, la configuration est étendue au cache des requêtes de base de données et à un cache déporté pour les sessions.

Images et fichiers

Les photos sont converties au format WebP, redimensionnées selon l'affichage, et celles situées hors de l'écran ne se chargent qu'au défilement. Feuilles de style, scripts et polices sont minifiés, compressés, versionnés et servis avec une validité longue : le navigateur ne les retélécharge qu'en cas de changement réel. Les polices sont préchargées pour éviter le texte qui saute au chargement.

Envoi d'e-mails en arrière-plan

Quand un visiteur envoie un formulaire, la confirmation s'affiche immédiatement : l'e-mail part en arrière-plan. Sans ce mécanisme, la page reste bloquée le temps que le serveur de messagerie réponde, parfois plusieurs secondes, et le visiteur croit que rien ne s'est passé, renvoie le formulaire, ou quitte le site.

Les envois sont mis en file d'attente et traités par un service dédié. Si le serveur de messagerie est momentanément indisponible, le message n'est pas perdu : il est réessayé automatiquement. Le même principe s'applique aux traitements longs, comme le redimensionnement d'images ou l'export de données.

Isolation des services

Application, base de données et traitements différés tournent dans des conteneurs séparés derrière le serveur web. Un incident sur l'un n'entraîne pas les autres, et une mise à jour se déploie sans interrompre le site.

Mesures relevées sur un site en production, azur-trad.fr, hébergé sur cette infrastructure : 0,12 seconde de temps de réponse serveur sur page mise en cache, en-têtes s-maxage=240 pour les pages et max-age=2592000, immutable pour les fichiers statiques, images en WebP et chargement différé, site publié en quatre langues avec balises hreflang.
